# CLAUDE.md

Exploratory GTDB / type-strain scripts, not part of the run order. Easy to get wrong:

- Output goes to `data/lit/gtdb/` and `output/lit/`, under `$KANSASII_ROOT`.
- `05_gtdb_adv_search_genomes.sh` downloads genomes from NCBI; run it only when that is intended.
- `lit_download.ps1` is PowerShell, for a Windows machine.
- Default branch is `main` (the other repos use `master`).
